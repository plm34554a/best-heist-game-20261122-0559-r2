Midnight Gallery is a top-down stealth heist game: cross three rooms past patrolling guards with sweeping vision cones and rotating security cameras, steal each room's treasure, and reach the green exit before the alarm meter hits 100 — with several routes per room, vents to hide in, and smoke bombs, EMP pulses and coin tosses bought with stolen loot.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrow keys (or click to walk), press Space to grab loot, and press 1 / 2 / 3 — or click the side-panel buttons — to use tools. Steal the room's target, then reach the green EXIT pad to escape to the next room.
